# Digest 07 — 14 pillars of Agentic AI (parallelism)

**Source:** Fareed Khan · 2025-11-21  
**URL:** https://levelup.gitconnected.com/building-the-14-key-pillars-of-agentic-ai-229e50f65986  
**Repo:** https://github.com/FareedKhan-dev/agentic-parallelism

## Pillars (orchestration toolkit)

1. Parallel tool use (hide I/O latency)  
2. Hypothesis generation / strategic exploration  
3. Parallel evaluation / governance  
4. Speculative execution  
5. Hierarchical agent teams (manager → workers)  
6. Competitive ensembles (pick best answer)  
7. Agent assembly line (high volume)  
8. Decentralized blackboard collaboration  
9. Redundant execution (fault tolerance)  
10. Parallel query expansion  
11. Sharded / scattered retrieval  
12. Parallel hybrid search fusion  
13. Parallel context pre-processing  
14. Multi-hop retrieval  

## Key insight

Bottleneck is often **I/O wait**, not LLM tokens — parallelize independent tool calls.

## Skill mapping

→ Choose topology (hierarchy / ensemble / assembly line / blackboard) before coding nodes.
