## Thesis

Production agents are **layered infrastructure**, not a single chat loop: orchestration, memory, security, scalability, fault handling.

## Typical layers

- Agent orchestration runtime  
- Memory / state persistence  
- Auth (JWT), sanitization, abuse rate limits  
- Connection pooling / resilience  
- Observability and failure modes
